# Source Inventory

Initial policy: use only official Fairfax County or Fairfax-hosted sources unless the project owner approves otherwise. The project owner has approved `plus.fairfaxcounty.gov` as a Fairfax-hosted routing source. This inventory records recommended first sources for Phase 1 download and review. No documents have been downloaded yet.

## Approval Status Values

- `Recommended`: candidate source identified, pending project-owner approval.
- `Approved`: explicitly approved for prototype use.
- `Rejected`: not approved for prototype use.
- `Needs review`: useful source, but ownership, currency, sensitivity, or hosting needs confirmation.
